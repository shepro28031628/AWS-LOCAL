# S3: almacenamiento de archivos

[Volver al índice](README.md)

## Qué es y cuándo usarlo

**Amazon S3** (*Simple Storage Service*) guarda archivos de cualquier tipo y tamaño: fotos, PDFs, copias de seguridad, datos para análisis, páginas web... Es el servicio más usado de AWS y la base de casi todos los proyectos.

Úsalo cuando necesites:

- Guardar archivos que suben los usuarios de una aplicación.
- Montar un **data lake** (lago de datos) para analítica.
- Publicar una **web estática** (HTML, CSS, JS).
- Guardar copias de seguridad con historial de versiones.

## Conceptos clave

| Concepto | Qué es |
|---|---|
| **Bucket** | Contenedor principal de archivos. Su nombre es único, en minúsculas y sin espacios |
| **Objeto** | Un archivo guardado en un bucket, más sus metadatos |
| **Key (clave)** | El nombre completo del objeto, incluidas las "carpetas": `2026/notas/ana.pdf` |
| **Prefijo** | La parte inicial de una key, que funciona como carpeta: `2026/notas/` |
| **Versionado** | Guarda todas las versiones de cada objeto en vez de sobrescribirlo |
| **Metadatos** | Datos sobre el archivo: tipo de contenido, autor, etc. |
| **URL prefirmada** | Enlace temporal para descargar un archivo privado sin credenciales |
| **Política de bucket** | Reglas en JSON que dicen quién puede hacer qué |

## Antes de empezar

1. AWS Nube Local encendido ([manual 1](01-instalar-y-arrancar.md)).
2. Terminal configurada ([manual 3](03-configurar-aws-cli.md)).
3. Crea una carpeta de trabajo vacía y entra en ella. Ahí guardarás los archivos de los ejercicios.

> Hay dos familias de comandos: `aws s3 ...` (sencillos, como en un explorador de archivos) y `aws s3api ...` (todas las opciones de la API). Usaremos las dos.

## Ejercicio 1: operaciones básicas

```bash
aws s3 mb s3://docs-clase
```

Crea un archivo `nota.txt` con el texto `version 1` y súbelo:

```bash
aws s3 cp nota.txt s3://docs-clase/
```

```bash
aws s3 ls s3://docs-clase
```

Descárgalo con otro nombre:

```bash
aws s3 cp s3://docs-clase/nota.txt copia.txt
```

## Ejercicio 2: carpetas y sincronización

Las "carpetas" en S3 son solo prefijos del nombre:

```bash
aws s3 cp nota.txt s3://docs-clase/2026/noviembre/nota.txt
```

```bash
aws s3 ls s3://docs-clase --recursive
```

Crea una carpeta local `proyecto` con dos archivos (`a.txt` y `b.txt`) y sincronízala:

```bash
aws s3 sync proyecto s3://docs-clase/proyecto/
```

Borra `b.txt` en tu PC y sincroniza con `--delete`: S3 queda igual que tu carpeta.

```bash
aws s3 sync proyecto s3://docs-clase/proyecto/ --delete
```

> `sync` solo sube lo que cambió. Es la forma habitual de publicar una web o hacer copias de seguridad.

## Ejercicio 3: versionado (historial de cambios)

Activa el versionado:

```bash
aws s3api put-bucket-versioning --bucket docs-clase --versioning-configuration Status=Enabled
```

Edita `nota.txt` para que diga `version 2` y súbelo otra vez:

```bash
aws s3 cp nota.txt s3://docs-clase/nota.txt
```

Mira todas las versiones:

```bash
aws s3api list-object-versions --bucket docs-clase --prefix nota.txt --query "Versions[].{Id:VersionId,Ultima:IsLatest,Fecha:LastModified}" --output table
```

Recupera la versión antigua copiando su `Id` de la tabla:

```bash
aws s3api get-object --bucket docs-clase --key nota.txt --version-id PEGA_EL_ID antigua.txt
```

`antigua.txt` contiene `version 1`.

Ahora borra el archivo:

```bash
aws s3 rm s3://docs-clase/nota.txt
```

Ya no aparece en `aws s3 ls`, pero **no se perdió**: S3 añadió un "marcador de borrado". Las versiones siguen ahí:

```bash
aws s3api list-object-versions --bucket docs-clase --prefix nota.txt
```

> Así se protegen los datos contra borrados accidentales. Para restaurar, borra el marcador de borrado (`aws s3api delete-object --bucket docs-clase --key nota.txt --version-id ID_DEL_MARCADOR`).

## Ejercicio 4: metadatos y etiquetas

Sube un archivo indicando su tipo y metadatos propios:

```bash
aws s3 cp nota.txt s3://docs-clase/informe.txt --content-type text/plain --metadata autor=ana,curso=bigdata
```

Consulta los datos del objeto sin descargarlo:

```bash
aws s3api head-object --bucket docs-clase --key informe.txt
```

Añade etiquetas (sirven para clasificar, buscar o aplicar reglas):

```bash
aws s3api put-object-tagging --bucket docs-clase --key informe.txt --tagging "TagSet=[{Key=estado,Value=revisado}]"
```

```bash
aws s3api get-object-tagging --bucket docs-clase --key informe.txt
```

## Ejercicio 5: compartir con una URL prefirmada

Genera un enlace válido 5 minutos (300 segundos):

```bash
aws s3 presign s3://docs-clase/informe.txt --expires-in 300
```

Copia la URL y ábrela en el navegador: descarga el archivo sin pedir credenciales. Pasados 5 minutos deja de funcionar.

> Es lo que usan las apps para que un usuario descargue (o suba) un archivo privado directamente a S3.

## Ejercicio 6: reglas de ciclo de vida

Crea `ciclo.json` para borrar automáticamente lo que haya en `temp/` a los 7 días:

```json
{
  "Rules": [
    {
      "ID": "borrar-temporales",
      "Filter": { "Prefix": "temp/" },
      "Status": "Enabled",
      "Expiration": { "Days": 7 }
    }
  ]
}
```

```bash
aws s3api put-bucket-lifecycle-configuration --bucket docs-clase --lifecycle-configuration file://ciclo.json
```

```bash
aws s3api get-bucket-lifecycle-configuration --bucket docs-clase
```

> En AWS real también se usan para mover archivos viejos a almacenamiento más barato (por ejemplo *Glacier*).

## Ejercicio 7: avisar a otro servicio cuando se sube un archivo

S3 puede mandar un mensaje a una cola SQS cada vez que llega un archivo. Es la base de muchos procesos automáticos (por ejemplo, "cuando suban una foto, genera la miniatura").

Crea la cola:

```bash
aws sqs create-queue --queue-name subidas
```

Crea `notificacion.json`:

```json
{
  "QueueConfigurations": [
    {
      "QueueArn": "arn:aws:sqs:us-east-1:000000000000:subidas",
      "Events": ["s3:ObjectCreated:*"]
    }
  ]
}
```

```bash
aws s3api put-bucket-notification-configuration --bucket docs-clase --notification-configuration file://notificacion.json
```

Sube un archivo y lee la cola:

```bash
aws s3 cp nota.txt s3://docs-clase/nuevo.txt
```

```bash
aws sqs receive-message --queue-url http://localhost:4566/000000000000/subidas --max-number-of-messages 10
```

Verás dos mensajes: uno `s3:TestEvent` (S3 lo manda al configurar, para probar la conexión) y otro con `"eventName":"ObjectCreated:Put"` y `"key":"nuevo.txt"`.

## Ejercicio 8: publicar una web estática

```bash
aws s3 mb s3://web-clase
```

Crea `index.html`:

```html
<h1>Mi web en AWS Nube Local</h1>
<p>Publicada desde S3.</p>
```

```bash
aws s3 cp index.html s3://web-clase/
```

```bash
aws s3 website s3://web-clase/ --index-document index.html
```

Para que cualquiera pueda leerla hace falta una política pública. Los buckets nuevos **bloquean el acceso público** por seguridad (igual que en AWS real), así que primero quita ese bloqueo:

```bash
aws s3api delete-public-access-block --bucket web-clase
```

Crea `politica.json`:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "LecturaPublica",
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::web-clase/*"
    }
  ]
}
```

```bash
aws s3api put-bucket-policy --bucket web-clase --policy file://politica.json
```

Abre en el navegador: <http://web-clase.s3-website-us-east-1.localhost:4566/>

## Reto

1. Crea un bucket `galeria-TUNOMBRE` con versionado activado.
2. Sube tres imágenes dentro de `fotos/` con el metadato `autor=TUNOMBRE`.
3. Configura una regla que borre `fotos/borrador/` a los 3 días.
4. Genera una URL prefirmada de 1 hora para una de las fotos y ábrela en el navegador.
5. Sube una nueva versión de una foto y recupera la anterior.

## Chuleta

| Quiero... | Comando |
|---|---|
| Crear / borrar bucket | `aws s3 mb s3://B` / `aws s3 rb s3://B --force` |
| Subir / descargar | `aws s3 cp ORIGEN DESTINO` |
| Listar todo | `aws s3 ls s3://B --recursive` |
| Sincronizar carpeta | `aws s3 sync CARPETA s3://B/prefijo/ --delete` |
| Versionado | `aws s3api put-bucket-versioning --bucket B --versioning-configuration Status=Enabled` |
| Ver versiones | `aws s3api list-object-versions --bucket B` |
| Info sin descargar | `aws s3api head-object --bucket B --key K` |
| Enlace temporal | `aws s3 presign s3://B/K --expires-in SEGUNDOS` |
| Web estática | `aws s3 website s3://B/ --index-document index.html` |
